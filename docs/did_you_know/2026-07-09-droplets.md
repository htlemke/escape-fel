# Photon counting with droplets (experimental)

`find_droplets` joins neighbouring pixels hit by one photon, and returns
cleaned images, a sparse list of droplets, or per-event photon-multiplicity
histograms with a Poisson fit. Runs chunk by chunk on stacks of any size.
Experimental, for testing.

```python
from escape.utilities_detectors import find_droplets
clean = find_droplets(images, threshold=15.0)
```
