# Overlay yesterday's curve on today's plot

The **History** button saves ticked curves with a note, and recalls saved
curves onto any plot, with the best matches (titles, axis labels, x-range,
Array name, run) listed first. A shared history folder lets colleagues
recall each other's curves.

```python
fig = nfigure(history_button=True)
```
