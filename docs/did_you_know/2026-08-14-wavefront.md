# Talbot wavefront reconstruction (experimental)

`escape.wavefront` reconstructs the X-ray wavefront from Talbot grating
images (gradients, curvature, focus position) and back-propagates complex
fields over a whole run with dask. Experimental, for testing.

```python
from escape import wavefront
```
