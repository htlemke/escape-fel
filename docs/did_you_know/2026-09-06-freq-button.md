# Look for periodicities straight from a plot

The **Freq** button computes a Welch or plain power spectrum, a Lomb-Scargle
spectrum for unevenly spaced x, a spectrogram or a wavelet scalogram of a
curve on the axes, e.g. to find a periodic disturbance in a time trace.

```python
fig = nfigure(freq_button=True)
```
