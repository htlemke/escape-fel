# Thin out a busy plot without re-plotting

The **Select** button lists the curves of the axes with a checkbox each,
plus a filter box. Hidden curves leave the legend and the y-range is
refitted to what is left.

```python
attach_select_button(fig)   # once the curves are drawn
```
