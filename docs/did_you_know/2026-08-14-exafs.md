# EXAFS reduction from μ(E) to χ(R) (experimental)

`escape.exafs` does pre-edge, normalisation, background removal and Fourier
transform, for a single spectrum or lazily for one spectrum per event of an
Array. Experimental, for testing.

```python
from escape import exafs
chi = exafs.reduce_array(mu_arr, energy, kgrid)
```
